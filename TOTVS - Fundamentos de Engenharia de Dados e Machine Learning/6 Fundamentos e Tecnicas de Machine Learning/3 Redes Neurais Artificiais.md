# Redes Neurais Artificiais

## 1 Redes Neurais Artificiais (RNA)

Redes neurais são interligações dos neurônios no cérebro. Os cientistas da computação recriaram para solucionar.

### Estrutura da RNA

Algoritmo de computador baseado em um neurônio real:

Possui interligação de neurônios, cada um com pesos para treino.

Recebe valores de entrada para gerar um valor de saída.

No núcleo tem uma função de ativação.

- Sinais de entrada
- Pesos sinápticos
- Combinador Linear
- Função de ativação
- Sinal de saída

## 2 Treinamento de uma Rede Neural Artificial

Nossa visão, os olhos são as entradas, nisso é processada e a saída são dados interpretados: *"Ah, é um astronauta na Lua"*

Quando um algoritmo recebe uma imagem de entrada, ele processa matrizes com pequena partes da imagem.

No exemplo de um gato, iria determinar que as pedaços de imagem que determinal o animal seria:

- orelha
- focinho
- olhos
- rabo

As imagens são sempre interpretadas como dados

## 3 Classificação: Execução da Rede Neural Artificial

Matrizes convulacionais,
cada pedaço da imagem é lido pela matriz
e todas as matriz vão ser unidas
e no final vamos ter a respostas.
