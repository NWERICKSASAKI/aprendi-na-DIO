# Introdução ao Machine Learning

## 1 Introdução ao Machine Learning

**Inteligência Artificial Restrita** refere-se a sistemas de IA projetados e treinados para realizar tarefas específicas e domínio limitados, não possuindo capacitdade de generalizar suas habilidades além do que foram programados. (Ex: A IA do sistema de recomendação do YouTube não consegue elaborar uma receita de bolo ou dirigir um carro)

**Teste de Turing** testa a capacidade de uma máquina exibir comportamento inteligente equivalente a um ser humano, ou indistinguível deste.

**Robô Sophia**, primeiro robô a obter cidadania, capaz de reproduzir 62 expressões faciais (mas não passou no teste de Turing).  

Por meio do **Machine Learning** obtemos (ou não) uma **Inteligência Articifical** restrita.

Para ser **IA**, precisa conseguir generalizar com base no que foi ensinado.

O objetivo do **Machine Learning** é programar computadores para aprender um determinado comportamento ou padrão automaticamente a partir de exemplos ou observações (*datasets*).

Para treinar uma IA para reconhecer alunos de uma sala de aula, seria necessário de 40 a 50 imagens faciais de cada.
